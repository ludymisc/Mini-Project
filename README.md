Proyek ini melakukan pengaplikasian metode statistik z-score pada kolom `Fare` dari dataset Titanic untuk mempelajari distribusi rata-rata sampel.  
Tujuan utamanya adalah memberikan ilustrasi sederhana tentang teknik resampling dalam statistik menggunakan Python.
